# 概要
## 機能
* UXに優れる画面
* 指定したディレクトリ配下のパワーポイント、エクセル、ワード、.md、.txt、PDFなどを入力したもの文字列でファイル内を検索できる
 * 検索条件はチェックボックスなどで(もっと良いのがあればその限りでない) 様々指定できるようにしたい。
 * 検索前に画面の左側にフォルダ配下のファイル一覧を一覧表にして表示してほしい。
 * 検索後はマッチしたファイルだけがひょうじされる。
 * カラムは通し番号ファイル名、拡張子ボタン、Path(Pathのところに右クリックするとメニューが出てきてそのファイルを開く項目とPathをとれる項目がある。)、該当文字列の検出数が表示される(ただし、50個を超えたらそれ以上はそのファイルは読まなくていい50をこえたら50>と表示)、インフォメーションチップでマウスオーバーすると作者、作成日
 * 画面の右側はプレビュー画面で上側はマッチした分のプルダウンがあってそこで選んだもののパワーポイント、エクセル、ワード、.md、.txt、PDFのマッチ部分をあたかも直接的に見れるようになっていて欲しい。その右に通常はグレーアウトだが複数ページあるいは複数シートにマッチがあった場合は切り替えられるようにしたい。
 * プレビューの部分ではマッチした個所を分かりやすくマークアップするようにして、PDFの場合はおそらくあたかもPDFのように見えるように知るには文字列検索が難しそうだか文字列処理をしてその後に表示部分に手を入れるとかがいいのか。
 
* pyside6を使う、pipでなくuvを使用する。
