# UI仕様書（草案）— Unified-File-Search-Tool

## 1. 画面構成
単一画面で完結する。

- 左ペイン: 検索条件 + ファイル一覧（検索前は母集団、検索後は結果）
- 右ペイン: プレビュー（マッチ箇所単位で表示）

## 2. 主要ユーザーフロー
### 2.1 検索前
1. 対象ディレクトリを指定
2. 左ペインの一覧表に「フォルダ配下のファイル一覧」を表示

### 2.2 検索
1. 検索語を入力
2. 表層の検索条件（ON/OFF）を必要に応じて切替
3. 詳細設定（Advanced）を必要に応じて開く
4. 検索実行
5. 検索中は進捗表示（プログレスバー + % + 処理済み/総数）を確認
6. 検索中はESCキーで中断できる

### 2.3 検索後
- 左ペインの一覧表は「マッチしたファイルのみ」を表示
- 右ペインでマッチ箇所単位にプレビュー確認

## 3. 左ペイン仕様
### 3.1 検索条件エリア
#### 3.1.1 入力
- 検索語入力欄

#### 3.1.2 表層（ON/OFF）
- 拡張子フィルタ（対象拡張子を選択する）
- 大小文字区別
- 正規表現
- 全文一致（完全一致）
- 一部一致（部分一致）

※「全文一致」と「一部一致」は同時ON不可（排他）を基本とする。

##### 3.1.2.1 拡張子フィルタ（ポップアップ）
- 拡張子フィルタは「ボタン」押下でポップアップを開く
- ポップアップ内に、対象ディレクトリに存在する拡張子一覧を表示する
  - 各拡張子の先頭にチェックボックスを表示する
  - チェックONの拡張子のみ一覧/検索対象にする
- ディレクトリ変更時はポップアップの拡張子候補を更新する

##### 3.1.2.2 正規表現（リッチ入力支援）
  - よく使うパターン挿入ボタン（少数精鋭）
    - `.*`
    - `\\s*`
    - `\\d+`
    - `^`
    - `$`
    - `|`
    - `(...)`
    - `(?:...)`
  - 正規表現のオプション選択（3つに絞る）
    - Ignore case（大小無視）
    - Multiline（`^`/`$` を行単位にする）
    - Dot matches newline（`.` が改行も含む）
  - 例: ボタン押下でカーソル位置に挿入／手入力で式が変わったらそのまま反映

#### 3.1.3 詳細設定（Advanced）
- 除外語
- サブフォルダ検索の有無
- ファイルサイズ上限
- 更新日範囲

※ファイルサイズ上限を超えるファイルは、検索対象から除外（スキップ）する。

#### 3.1.4 進捗表示（検索中）
- プログレスバーを表示する
- 進捗率（0–100%）を数値で表示する
- 進捗率は総ファイルサイズ（bytes）を母数にした割合とする
- `処理済みbytes/総bytes` を表示する
- 併せて `処理済み/総数`（例: `37/210`）も表示できる

### 3.2 一覧表（ファイル一覧 / 検索結果一覧）
#### 3.2.1 表示切替
- 検索前: 対象フォルダ配下のファイル一覧
- 検索後: マッチしたファイルのみ

#### 3.2.2 カラム定義
- No（通し番号）
- ファイル名
- 拡張子（ボタン）
- Path
  - 右クリックメニュー
    - ファイルを開く
    - Pathをコピー
- 検出数
  - 50件を超えたらそれ以上は読み取らず、表示は `50>`
- Info（インフォメーションチップ）
  - マウスオーバーで作者、作成日を表示（Officeプロパティ）

## 4. 右ペイン仕様（プレビュー）
### 4.1 ヘッダー領域
- マッチ箇所プルダウン
  - 粒度: マッチ箇所単位
  - 選択したマッチ箇所をプレビューに反映
- フルロードボタン
  - 選択されたファイルのみ、全体をプレビュー表示する
  - 全体表示中もマッチ箇所の強調表示を維持する
  - 対象ファイルが大容量閾値を超える場合は警告を表示し、OKした場合のみ読み込む
  - 大容量警告は主にこのフルロード（全体プレビュー）で適用する
  - フルロード後はスクロールバーでファイル全体を連続的に閲覧できる
- ページ/シート切替
  - 通常: グレーアウト（無効）
  - 条件: 複数ページ（PDF等）または複数シート（Excel等）にマッチがある場合のみ有効
- ズーム操作
  - 拡大（＋）
  - 縮小（－）
  - 等倍に戻す（100%）

### 4.2 表示領域
- 対象: PowerPoint / Excel / Word / PDF / `.md` / `.txt` / `.log`
- 目標: 画像や表も含め、HTMLで再構成し「現物を見ている」ように表示する
- マークアップ
  - マッチした文言は強調表示し、視認性を上げる（誇張できる表現）

#### 4.2.1 ページ相当
- PDF / Word / PowerPoint は、プレビュー上で「1ページ相当」の単位で表示できること
  - PDF: ページ
  - Word: 1ページ相当
  - PowerPoint: スライド（= 1ページ相当）

### 4.3 右下表示（文字コード）
- `.txt` / `.md` / `.log` のプレビュー表示中は、採用した文字コードを画面右下（淵）に表示する
  - 文字コード判別/変換は日本語利用を前提に **CP932（Windows-932）** を優先する

## 5. 状態と表示ルール（要点）
- 右ペインは「左の選択」または「マッチ箇所プルダウン選択」で表示内容が決まる
- ページ/シート切替は、切替対象が存在する場合のみ有効
- ズームはプレビュー表示されている内容すべてに適用される

## 6. UI品質
- UIは常にモダンで、視認性と操作性を優先する
- 検索中はユーザーが不安にならないよう、進捗表示（バー/%/処理済み/総数）を継続的に更新する

## 7. コピー
- 画面に表示される情報は、基本的にコピーできる（例: 一覧のセル、パス、プレビュー内テキスト等）
- 画面上の文言・値は右クリックでコンテキストメニューを表示し、「コピー」を実行できる
